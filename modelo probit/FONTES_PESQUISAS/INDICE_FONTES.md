# Índice do acervo de pesquisas

Pasta criada para conservar cópias locais das pesquisas usadas na base de segundo turno. O padrão de organização é:

`ano / cargo / local / arquivo`

O nome segue o formato:

`AAAA_2T_CARGO_UF-ou-BR_INSTITUTO_STATUS_AAAA-MM-DD.ext`

Os arquivos HTML são cópias congeladas das páginas consultadas. Em 2018, os quadros de resultados aparecem em gráficos/tabelas incorporados por páginas interativas; por isso o HTML preserva a página, a metodologia, o registro TSE e os percentuais publicados, mas não substitui um PDF metodológico integral.

## Próximo lote

O acervo deve ser ampliado por ano e disputa somente quando houver fonte preservável. Para cada nova pesquisa, conferir antes de transcrever: cargo, UF, segundo turno, data de campo, amostra, margem de erro, registro TSE, candidatos e denominador dos percentuais.
